→ חזרה לאפליקציה

במחשב (כרום)

  1. ודאי שסרגל הסימניות מוצג: Ctrl+Shift+B.
  2. גררי את הכפתור הזה אל סרגל הסימניות:
    עצב לנעמה
  3. בשירונט, כשאת בדף של שיר (מילים או אקורדים), לחצי על "עצב לנעמה" בסרגל.

באייפון (כרום)

  1. לחצי כאן כדי להעתיק את הקוד:
  2. בכרום, פתחי כל אתר, לחצי על ⋯ ואז הוספה לסימניות.
  3. פתחי את הסימניות (⋯ ← סימניות), לחצי לחיצה ארוכה על הסימנייה החדשה ← עריכת סימנייה.
  4. שם: נעמה. בכתובת: מחקי הכל והדביקי את הקוד. שמרי.
  5. בשירונט, בדף של שיר: הקלידי בשורת הכתובת נעמה ובחרי את הסימנייה מההצעות.
