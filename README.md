# נעמה שירתך – אפליקציית המקהלה

אפליקציה לעיצוב שירים על דף הלוגו של המקהלה, להדפסה.

- כתובת: https://shtatlerit.github.io/Naama/
- הכפתור לשירונט: https://shtatlerit.github.io/Naama/install.html
- נתונים: Firebase (פרויקט `naama-choir`), כניסה עם חשבון Google מורשה בלבד.

מבנה: `index.html` (המסכים), `js/app.js` (לוגיקה ושמירה), `js/parse.js` (פענוח שיר, פזמונים, אקורדים), `js/layout.js` (עימוד והתאמה לעמוד), `js/grab.js` (הכפתור לשירונט), `css/page.css` (דף הלוגו להדפסה).
